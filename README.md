# csharp-database-connectivity-project
C# Windows Forms application demonstrating connections to local, imported, and remote SQL databases.
C# Database Connectivity Project
Overview
This project demonstrates how a C# Windows Forms application can connect to multiple SQL database environments, including local, imported, and remote databases.

The application was developed as part of my database programming coursework and provided hands-on experience working with database connectivity, SQL queries, and data management.

Technologies Used
C#
SQL Server
Windows Forms
Visual Studio
Features
Connect to a local database
Connect to an imported database
Connect to a remote database
Retrieve and display data
Execute SQL queries
Manage database connections
Skills Demonstrated
Database integration
SQL query development
Connection string configuration
Data retrieval and management
Software troubleshooting
Object-oriented programming
What I Learned
Through this project, I learned how applications interact with different database environments, how to troubleshoot connection issues, and how to integrate SQL databases into C# applications.

Note
Database credentials and connection information have been removed for security purposes.
